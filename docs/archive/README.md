# Archived planning docs

These files describe the project as it was planned before implementation. They
are kept for history only and are **not** current:

- `backend-completion-plan.md` — Phase 1.5 → 4 backend plan. Superseded by the
  shipped Supabase-only data layer and `docs/sql/0001`–`0005`.
- `implementation_plan.md` — original 10-phase plan. It still recommends a
  Firebase hybrid (Firestore/FCM) that the app no longer uses.
- `task.md` — the original checkbox tracker. Superseded by
  [`../TICKETS.md`](../TICKETS.md).

For the current state, schema, deployment steps and verification evidence, read
`docs/TICKETS.md`, `docs/sql/*.sql`, `SETUP.md` and `PROJECT_CONTEXT.md`.
